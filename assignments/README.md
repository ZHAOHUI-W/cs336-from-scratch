# Assignments

Put A1–A5 code here (or as git submodules / separate folders per assignment).

Suggested layout once you clone official starters:

```
assignments/
  a1-basics/
  a2-systems/
  a3-scaling/
  a4-data/
  a5-alignment/
```

**Workflow**
1. Stub an ADR in `docs/design/` for the hard piece
2. Implement behind a clear adapter/interface (match course tests)
3. CPU correctness → cloud GPU for trains/benchmarks
4. Tick `PROGRESS.md` + journal

Do not commit huge checkpoints, datasets, or WARC dumps — see root `.gitignore`.
